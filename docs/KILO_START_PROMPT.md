# Kopieer deze opdracht naar Kilo Code

Werk aan deze repository voor Egg Riders. Lees eerst README.md, alle docs en .kilo/rules/project.md. Dit is een scaffold, geen complete game.

1. Rapporteer kort wat aanwezig is, wat ontbreekt en welke aannames nog onbevestigd zijn.
2. Audit mijn computer read-only: Git, VS Code/Kilo, Roblox Studio, Rojo en bestaande Ollama/Flux/Antigravity waar toegankelijk. Vraag toestemming voor installatie, administratorrechten, betaalde acties, grote downloads en destructieve wijzigingen. Lees geen secrets.
3. Voer T00 uit. Gebruik officiële installatiebronnen; leg exacte toolversies vast. Als Studio niet te bedienen is, geef specifieke handmatige stappen en meld dat Studio-test niet uitgevoerd is.
4. Maak vervolgens alleen T01: egg pickup/carry/delivery, eigen ranch en servervalidatie. Bouw een kleine graybox in een nieuwe lokale test-place. Niet hatch, riding, combat of volledige game tegelijk bouwen.
5. Werk met kleine reviewbare wijzigingen, inspecteer git diff, voer beschikbare tests uit en werk docs/STATUS.md bij. Maak geen commit/push zonder mijn toestemming.
6. Stop na T01 met een concreet verslag: bestanden, testbewijs, resterende risico's en volgende ticket. Verwar gegenereerde code niet met getest gedrag.

Geen live-publicatie, productie-place sync, betaalproducten, trading of PvP in deze fase. Het verdere plan staat in docs/BACKLOG.md.
